Telegram-агент для мониторинга фриланс-заказов

Задача
Находить свежие IT-заказы, на которые можно откликнуться бесплатно, и сокращать время на подготовку предложений.
Решение
Служба на Ubuntu проверяет RSS FL.ru каждые 15 минут, выбирает заказы с отметкой «Для всех» и отправляет их в Telegram. Локальный процесс на Windows получает заявки по SSH, готовит черновики через Codex CLI в пределах дневной квоты и возвращает их ответом на исходное сообщение. Очередь и отметки о доставке сохраняются между запусками.
Результат
Проверена доставка заявок и двух сгенерированных черновиков. Сбор заявок работает на VPS, генерация доступна при включённом ПК. Отклик на бирже отправляет исполнитель.
Технологии
PowerShell, Python, Telegram Bot API, RSS, SSH, systemd, Codex CLI, Планировщик заданий Windows.

CRM мебельной компании

Задача
Упростить работу с дедлайнами менеджеров и перенести график производственного цеха в CRM.
Решение
В CRM появился календарь задач с фильтром по ответственному, режимами месяца, недели, дня и повестки и переходом в карточку задачи. Для цеха добавлен отдельный модуль графика. Также настроена автоматическая подстановка клиента из лида при создании связанной задачи.
Результат
Календарь проверен в рабочей CRM. Модуль графика развёрнут на рабочем сервере, загружено 366 записей за два месяца. Связь клиента проверена в карточках тестовых задач.
Технологии
PHP, SQL, FullCalendar, настройка CRM.
Восстановление

Восстановление интернет-магазина из резервной копии

Задача
Восстановить магазин OpenCart и его базу данных на другом VPS.
Решение
Восстановлены приложение и база. Настроена связка Caddy, Nginx и PHP, подготовлена конфигурация домена и автоматического выпуска HTTPS-сертификата.
Результат
Доступность магазина с базой на новом сервере подтверждена. Переключение домена и HTTPS зависели от обновления DNS. Изображения в объём восстановления не входили.
Технологии
OpenCart, PHP, Nginx, Caddy, DNS, Linux.

Туристический сайт в Адыгее

Задача
Представить размещение и варианты активного отдыха на отдельных страницах и принимать заявки посетителей.
Решение
Подготовлены страницы гостиницы и подбора отдыха, форма заявки и разделы с вариантами активностей и ценами. В проекте есть редактор контента и хранение заявок в SQLite.

Технологии
Python, SQLite, HTML, CSS, JavaScript.

Локальный проект

Forecaster для планирования загрузки сотрудников

Задача
Видеть дефицит сотрудников по часам и понимать, когда можно согласовать дополнительный отпуск.
Решение
В месячной таблице по датам и должностям отображаются отсутствующие, лимит и доступные места для отпуска. При расчёте учитывается почасовое покрытие. При необходимости интерфейс показывает рекомендуемую дополнительную смену.
Результат
Приложение запущено локально, проверена доступность веб-интерфейса. Статус — локальный проект.
Технологии
Python, веб-интерфейс, расчёт покрытия смен.
Локальная проверка

Фильтрация спама в формах WordPress

Задача
Сократить число спам-заявок из форм сайта, которые попадают администратору в Telegram.
Решение
Для формы подписки добавлена проверка имён, похожих на автоматически сгенерированные строки. Срабатывания сохраняются в карантине до отправки уведомления.
Результат
Проблемная заявка блокируется в тестах, обычные имена проходят. Статус — доработка проверена локально.
Технологии
PHP, WordPress, формы, Telegram.
